## Принципы (неготиабельные)

1. **Органика в приоритете.** Платная реклама (Директ) — только после 20+ проиндексированных страниц.
2. **Гибридный контент:** 70% SEO-статьи + 20% научный дайджест + 10% FAQ.
3. **ИИ = советчик.** Генерирует черновик. Последнее слово — за врачом (Валентиной Андреевной).
4. **УТП в каждой статье:** "49 лет практики, 1-й МГМУ им. Сеченова, 1977".
5. **Никакой запрещёнки.** Строгий фильтр слов в промптах.
6. **2 часа/неделю** на проверку → 1-2 статьи глубокой проработки.

## Структура контента

### Тип A: SEO-статья (70%, 1-2/неделю)
- Объём: 1500-2000 слов
- Цель: ранжирование по СЧ/НЧ ключевикам
- Пример: "Остеохондроз шейного отдела: 7 ранних симптомов"

### Тип B: Научный дайджест (20%, 1/неделю)
- Объём: 500-800 слов перевода + 200 слов комментария врача
- Цель: E-E-A-T, доверие, уникальный контент
- Источник: PubMed Central (CC0/CC BY)
- Пример: "Новое исследование: акупунктура при мигрени (Meta-analysis, 2025)"

### Тип C: FAQ (10%, 2-3/месяц)
- Объём: 100-150 слов
- Цель: захват НЧ запросов, featured snippets
- Пример: "Почему болит голова по утрам?"

## Жёсткие правила для ИИ (промпт-фильтры)

### Запрещённые слова (автозамена или отказ генерации)
```
лечим, излечиваем, гарантия, 100%, навсегда, победим болезнь,
полное излечение, вылечим за 1 сеанс, чудо-метод, волшебная пилюля,
уникальная методика (без доказательной базы), секрет врачей
```

### Обязательные элементы в каждой статье
- [ ] УТП: "Гурьянова Валентина Андреевна, врач-невролог, 49 лет практики, 1-й МГМУ им. Сеченова, 1977"
- [ ] Дисклеймер: "Информация носит образовательный характер и не является медицинской услугой. Консультация врача необходима для постановки диагноза и назначения лечения."
- [ ] CTA: "Запишитесь на онлайн-консультацию" + телефон + ссылка
- [ ] Дата публикации и дата обновления
- [ ] Автор с фото (когда будет)

### Структура SEO-статьи
```
H1: [ключевик] — советы невролога с 49-летним стажем
├── Ввод (150 слов): проблема + обещание решения + УТП
├── H2: Что такое [ключевик] (200 слов)
├── H2: Причины [ключевик] (300 слов, маркированный список)
├── H2: Симптомы [ключевик] (250 слов, маркированный список)
├── H2: Когда обращаться к неврологу (200 слов)
├── H2: Методы лечения [ключевик] (400 слов)
│   ├── H3: Консервативное лечение
│   ├── H3: Рефлексотерапия
│   ├── H3: Гирудотерапия

```
