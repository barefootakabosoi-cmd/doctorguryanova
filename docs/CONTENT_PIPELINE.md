## Этап 1: Поиск статей (PubMed API)

**URL:** https://pubmed.ncbi.nlm.nih.gov/
**API:** https://eutils.ncbi.nlm.nih.gov/entrez/eutils/

**Бесплатно, не требует регистрации для базового поиска.**

### Поисковые запросы (примеры)
```
migraine treatment acupuncture
osteochondrosis cervical spine therapy
cerebrovascular disease prevention
insomnia non-pharmacological treatment
neuralgia trigeminal acupuncture
```

### API-запрос
```bash
# Поиск статей
https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=migraine+acupuncture+treatment&retmax=10&retmode=json

# Получение摘要 (abstract)
https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=PMID1,PMID2&rettype=abstract
```

### Фильтры (обязательно)
- Только статьи с **Abstract** (нет abstract = не берём)
- Желательно: **Free full text** (PMC — PubMed Central)
- Дата: последние 5 лет (не устаревшие)
- Тип: Review, Clinical Trial, Meta-analysis (высокий уровень доказательности)

## Этап 2: Проверка лицензии

**Какие статьи можно переводить:**

| Источник | Лицензия | Можно переводить? |
|----------|----------|-------------------|
| PubMed Central (PMC) | CC0, CC BY | ✅ Да, без разрешения |
| Open Access журналы | CC BY, CC BY-SA | ✅ Да, с атрибуцией |
| Государственные (CDC, NHS) | Public Domain | ✅ Да |
| Платные журналы (Elsevier) | All rights reserved | ❌ Нет, нужно разрешение |

**Как проверить:**
1. PMCID есть? → идём на https://www.ncbi.nlm.nih.gov/pmc/articles/PMCID/
2. Смотрим лицензию внизу страницы
3. Если CC0 или CC BY → берём

## Этап 3: ИИ-перевод (GigaChat)

**Промпт для перевода:**
```
Ты — медицинский переводчик и редактор.
Переведи на русский язык следующий научный abstract.

Правила:
1. Сохраняй все медицинские термины точно (можно дать перевод в скобках при первом упоминании)
2. Адаптируй структуру для чтения пациентом (не слишком академично)
3. Добавь краткое резюме для пациентов в конце (3-5 предложений)
4. Укажи: "Перевод сделан ИИ, проверен врачом. Оригинал: [ссылка с DOI]"
5. Добавь дисклеймер: "Информация носит образовательный характер..."

Abstract:
{text}
```

## Этап 4: Врач-редактор (Валентина Андреевна)

**Что проверяет:**
- ✅ Терминология (мигрень ≠ головная боль, рефлексотерапия ≠ иглоукалывание)
- ✅ Клиническая адекватность (не устаревшие данные)
- ✅ Добавляет комментарий: "Что это значит для пациента"
- ✅ Утверждает/отклоняет публикацию

**Формат публикации:**
```
H1: [Название статьи на русском]
  ├── Блок "Аннотация" (перевод abstract, 200-300 слов)
  ├── Блок "Ключевые выводы" (3-5 пунктов)
  ├── Блок "Что это значит для вас" (комментарий врача, 150-200 слов)
  ├── Блок "Оригинал" (ссылка на DOI, журнал, авторы)
  └── Дисклеймер + CTA
```

## Автоматизация (ИИ-агент)

**Что делает агент автоматически:**
1. Раз в неделю: ищет новые статьи в PubMed по ключевым словам
2. Фильтрует по лицензии (CC0/CC BY) и дате
3. Делает черновой перевод через GigaChat
4. Отправляет в Telegram-группу врачу на проверку
5. После approve — публикует на сайт

**Что делает человек:**
1. Проверяет перевод (терминология)
2. Добавляет комментарий "Что это значит для вас"
3. Нажимает "Опубликовать"
