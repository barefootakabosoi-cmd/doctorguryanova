# Органический трафик: максимум ключевых слов, минимум бюджета

## Принцип: Контент-машина

Google и Яндекс ранжируют сайты по:
1. **Релевантности** — ключевые слова в тексте, заголовках, мета-тегах
2. **Авторитетности** — ссылки, возраст домена, E-E-A-T (опыт, экспертность)
3. **Свежести** — регулярно обновляемый контент
4. **Техническому SEO** — скорость, мобильная версия, структура

## Архитектура контент-машины

```
ИИ (GigaChat/YandexGPT) → SEO-статьи → /blog/[slug]
                                    ↓
                         Sitemap.xml → Поисковики
                                    ↓
                         Internal links → Услуги (/nevrologiya/)
```

## Структура SEO-статьи (шаблон)

```
H1: [ключевик] — советы невролога с 49-летним стажем
  ├── Ввод (150 слов): проблема + обещание решения
  ├── H2: Что такое [ключевик] (200 слов)
  ├── H2: Причины [ключевик] (300 слов, список)
  ├── H2: Симптомы [ключевик] (250 слов, список)
  ├── H2: Когда обращаться к неврологу (200 слов)
  ├── H2: Методы лечения [ключевик] (400 слов)
  │   ├── H3: Консервативное лечение
  │   ├── H3: Рефлексотерапия
  │   ├── H3: Гирудотерапия
  │   └── H3: Остеопатия
  ├── H2: Профилактика (200 слов)
  ├── H2: Часто задаваемые вопросы (3-5 FAQ)
  └── Заключение + CTA: "Запишитесь на онлайн-консультацию"
```

## E-E-A-T для медицинского сайта (критично!)

Google и Яндекс требуют для YMYL (Your Money Your Life):

- **Experience (Опыт)**: 49 лет практики, реальные кейсы
- **Expertise (Экспертность)**: 1-й МГМУ им. Сеченова, 1977
- **Authoritativeness (Авторитетность)**: отзывы, упоминания, ссылки
- **Trustworthiness (Доверие)**: дисклеймер, контакты, политика

**Каждая статья должна содержать:**
- Автор: Гурьянова В.А., врач-невролог, 1-й МГМУ
- Дата публикации и обновления
- Дисклеймер: "Информация носит образовательный характер..."
- Ссылки на научные источники (желательно)
- Фото автора (когда будет)
