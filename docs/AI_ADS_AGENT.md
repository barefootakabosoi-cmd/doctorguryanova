## Почему НЕ полная автоматизация Директа?

1. **API Директа** требует OAuth, сложная авторизация
2. **Модерация объявлений** — медицинская тематика, могут отклонить
3. **Бюджет** — нужен реальный счёт, автосписания
4. **Риск** — ИИ может сгенерировать запрещённый контент (обещания исцеления)

**Решение:** ИИ делает 90% работы (анализ, тексты, ключевики), человек — 10% (проверка, запуск, бюджет).

## Компоненты агента

### 1. Сборщик данных (Data Collector)

**Источники:**
- Яндекс.Метрика API — визиты, источники, цели
- Google Analytics 4 API — аналогично
- Внутренняя БД — записи, конверсии, выручка

**Что собираем:**
```typescript
interface AnalyticsData {
  period: string;           // "2026-07-01" — "2026-07-31"
  totalVisits: number;
  organicVisits: number;    // из поиска
  directVisits: number;     // прямые заходы
  referralVisits: number;   // переходы
  bounceRate: number;       // % отказов
  avgSessionDuration: number;
  conversions: {             // цели
    bookingFormSubmit: number;
    paymentSuccess: number;
  };
  topPages: string[];        // самые посещаемые
  topQueries: string[];     // поисковые запросы (из Вебмастера)
}
```

## API Яндекс.Метрики

### Получение токена
1. https://oauth.yandex.ru/ → Создать приложение
2. Права: Яндекс.Метрика → Чтение
3. Получить OAuth-токен
4. Добавить в env: `YANDEX_METRIKA_TOKEN`

### Запросы
```bash
# Список счётчиков
curl "https://api-metrika.yandex.net/management/v1/counters"   -H "Authorization: Bearer $TOKEN"

# Статистика по источникам
curl "https://api-metrika.yandex.net/stat/v1/data?ids=YOUR_COUNTER_ID&metrics=ym:s:visits,ym:s:bounceRate&dimensions=ym:s:trafficSource&date1=7daysAgo&date2=today"   -H "Authorization: Bearer $TOKEN"
```

## API Яндекс.Директа (для справки)

### Получение токена
1. https://oauth.yandex.ru/ → Создать приложение
2. Права: Яндекс.Директ → Редактирование кампаний
3. Получить OAuth-токен
4. Добавить в env: `YANDEX_DIRECT_TOKEN`

### Создание объявления (пример)
```bash
curl -X POST "https://api.direct.yandex.com/json/v5/ads"   -H "Authorization: Bearer $TOKEN"   -H "Content-Type: application/json"   -d '{
    "method": "add",
    "params": {
      "Ads": [{
        "AdGroupId": 12345,
        "Title": "Невролог онлайн",
        "Title2": "49 лет стажа",
        "Text": "Консультация невролога онлайн. Запишитесь сейчас!"
      }]
    }
  }'
```

**⚠️ Важно:** Медицинские объявления требуют подтверждения лицензии. У вас консультационные услуги (не медуслуги), но Яндекс может запросить документы.

## План внедрения

### Этап 1: SEO-контент (неделя 1-2)
- Запустить блог /blog
- Опубликовать 4-6 статей
- Настроить sitemap.xml с /blog/*

### Этап 2: Аналитика (неделя 2-3)
- Подключить Яндекс.Метрику
- Подключить Google Analytics 4
- Настроить цели (отправка формы, оплата)

### Этап 3: ИИ-Агент (неделя 3-4)
- Написать скрипт сбора данных из Метрики
- Настроить генерацию отчётов через GigaChat
- Отправка в Telegram

### Этап 4: Директ (неделя 4+)
- Получить доступ к API Директа
- Сгенерировать первые объявления через ИИ
- Запустить тестовую кампанию (5000 ₽)
- Анализировать, корректировать
